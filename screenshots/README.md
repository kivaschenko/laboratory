# Screenshots

This directory contains screenshots of the Laboratory Management System interface to showcase the application's features and user interface.

## How to Add Screenshots

1. **Take Screenshots**: Capture images of key application screens
2. **Optimize Images**: Compress images for web viewing
3. **Name Consistently**: Use descriptive names like `dashboard.png`, `substances-list.png`
4. **Update README**: Add screenshots to the main README.md file

## Image Guidelines

- **Format**: PNG for UI screenshots, JPG for photos
- **Size**: Max width 1200px for large images, 800px for inline images
- **Quality**: High enough to show text clearly
- **Content**: Remove or blur any sensitive data
- **Consistency**: Use same browser/theme for all screenshots

## Tools for Screenshots

- **Browser Dev Tools**: For responsive design screenshots
- **Screenshot Tools**: 
  - macOS: Cmd+Shift+4
  - Windows: Snipping Tool or Snip & Sketch
  - Linux: GNOME Screenshot, Flameshot
- **Image Optimization**: TinyPNG, ImageOptim

## Note

Screenshots should be taken of a clean, well-configured instance with sample data that demonstrates the application's capabilities without revealing sensitive information.
